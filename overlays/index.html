How to load this into OBS Studio
  1. Launch OBS Studio. In the Sources dock, click the + button and select Browser.
  2. Name the source (e.g. GRiD UP Telemetry).
  3. Copy and paste the URL from the field above into the URL field.
  4. Set Width to 1920 and Height to 1080.
  5. Ensure Shutdown source when not visible is checked. Click OK!
